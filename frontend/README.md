# Front end

Static files, no build step: serve this folder and open `index.html`.

- `index.html`: the calendar
- `stats/index.html`: the stats page
- `src/app.js`: calendar rendering and interaction
- `src/composer.js`: the editor's post composer
- `src/data.js`: the post shape, loading and saving, and the sample posts
- `src/drive.js`: photo and video uploads to Google Drive
- `src/supabase.js`, `src/config.js`: the database client and Google sign-in
- `src/theme.js`: light and dark mode
- `src/styles.css`: all styling; colours and type are tokens at the top
- `src/stats*.{js,css}`: the stats page
- `assets/`: the logo, the mark and the sample post graphics
